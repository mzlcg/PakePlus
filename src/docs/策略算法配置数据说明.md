## 关键对象结构

### `algorithms[]`

| 字段 | 说明 |
| --- | --- |
| `id` | 算法唯一标识，如 `deepBid`、`arbitrage` |
| `displayName` | 页面显示名称 |
| `category` | 算法类别 |
| `coreFunction` | 核心功能 |
| `actionDefinition` | 动作定义 |
| `objective` | 优化目标 |
| `trainingBudget` | 训练预算或轮数 |
| `parameters[]` | 参数项列表 |

### `parameters[]`

| 字段 | 说明 |
| --- | --- |
| `label` | 参数名称 |
| `value` | 参数值 |
| `description` | 参数说明 |

## 页面选择逻辑

默认算法选择：

```text
selectedAlgorithmId =
  如果 algorithms 中存在 deepBid -> deepBid
  否则 -> algorithms[0].id
```

当前算法对象：

```text
selectedAlgorithm =
  algorithms.find(item => item.id === selectedAlgorithmId)
  || algorithms[0]
  || {}
```

年份选择：

```text
页面年份来自 MarketUI.selectedYear()
切换年份后调用 render(year)
```

## 参数匹配规则

页面通过两个辅助函数从 `parameters[]` 中取值：

### `paramValue(algorithm, patterns, fallback)`

```text
1. 遍历 algorithm.parameters[]
2. 查找第一个 label 包含 patterns 任一关键字的参数
3. 返回该参数的 value
4. 未命中时返回 fallback
```

### `paramDescription(algorithm, patterns, fallback)`

```text
1. 查找规则与 paramValue 相同
2. 优先返回 description
3. description 为空时返回 value
4. 未命中时返回 fallback
```

## 模块四：市场环境边界

| 页面字段 | 来源字段 | 公式/说明 |
| --- | --- | --- |
| 平均电价 | `summary.avgPrice` | 直接显示 |
| 电价范围 | `summary.minPrice`, `summary.maxPrice` | 文本格式为 `min-max` |
| 新能源占比 | `summary.renewableShare` | 直接显示 |
| 年度收益估算 | `summary.revenueWan` | 直接显示 |

相关公式来自 `scripts/build-data.ps1`：

```text
renewableShare = (windSum + solarSum) / (windSum + solarSum + thermalSum) × 100
revenueWan = Σ((wind + solar + thermal) × price × 0.25) / 10000
```

注意：

| 项 | 说明 |
| --- | --- |
| `controlScope` | 页面存在 DOM 节点，但当前脚本未赋值，默认显示 `--` |
| 注释掉的“策略组成说明”模块 | 当前页面未启用，不属于实际取数范围 |
