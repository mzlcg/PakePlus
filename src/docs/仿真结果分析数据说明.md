# 仿真结果分析页面数据说明

## 页面入口与直接依赖

| 项目 | 文件/对象 | 说明 |
| --- | --- | --- |
| 页面入口 | `analysis.html` | 仿真结果分析页面。 |
| 仿真数据 | `assets/visual-data.js` -> `window.VPP_VISUAL_DATA` | VPP 日切片仿真结果。 |
| 取数与图表逻辑 | `assets/analysis-visualization.js` | 日期/VPP/区间切换、KPI、主图计算。 |
| 训练曲线 | `assets/analysis-training-curves.js` | Reward / MAE / MBE 三类 VPP 曲线。 |

## 原始数据来源

`assets/visual-data.js` 中三个数据集分别来自：

| 数据集 | 原始文件 |
| --- | --- |
| `VPP1` | `part4 可视化/VPP1_风储运行数据记录.xlsx` |
| `VPP2` | `part4 可视化/VPP2_光储运行数据记录.xlsx` |
| `VPP3` | `part4 可视化/VPP3_光伏火电储能画图数据.xlsx` |

顶层对象结构：

| 字段 | 页面含义 |

| 项 | 口径 |

## 页面状态与筛选

持久化键：

| 键 | 含义 |
| --- | --- |
| `analysisSelectedVpp` | 当前分析对象 |
| `analysisSelectedDate` | 当前起始日期 |
| `analysisSelectedHorizon` | 当前区间长度 |
| `analysisSelectedTab` | 当前页签 |

状态归一化规则：

```text
selectedVpp:
  ALL 或 datasets 中存在的 VPP
  否则回退为 ALL

horizon:
  仅允许 1 或 3

tab:
  仅允许 bid / storage / revenue
```

日期集合规则：

```text
getAvailableDates(selectedVpp):
  单个 VPP -> datasets[selectedVpp].dates
  ALL -> 所有 datasets[id].dates 的交集

getSelectableDates(selectedVpp, horizon):
  从 availableDates 中截取可作为起点的日期
  结束索引 = dates.length - horizon
```

区间构造：

```text
rangeDates = 从起始日期开始连续取 horizon 天
slots = rangeDates × 96 个 15 分钟刻度
```

## 模块一：分析条件

| 控件 | 数据来源 | 规则 |
| --- | --- | --- |
| 日期 | `selectableDates` | 只允许共享数据区间内的日期 |
| 区间 | 页面固定值 | `1天` 或 `3天` |
| VPP | `getVppOptions()` | `全部 VPP` + `VPP1/VPP2/VPP3` |

## 模块二：指标概览

### 中间模型 `buildViewModel(rangeDates, selectedIds)`

该函数是页面所有 KPI 和图表的统一数据源。

#### 单个 VPP 单个时刻的派生量

```text
storageDelta_t = -(soc_eg_t - soc_eg_(t-1))
dispatch_t = gen_eg_t + storageDelta_t
batteryPower_t = storageDelta_t / 0.25
price_t = imb_eg_t
```

说明：

| 项 | 口径 |
| --- | --- |
| 上一时刻 | 直接取 `slots` 中前一个刻度，跨天时可引用前一天 `23:45` |
| 首个有效点 | 无上一时刻时，`storageDelta = 0` |

#### 多 VPP 聚合规则

```text
gen_t = Σ gen_t
bid_t = Σ bid_t
soc_t = Σ soc_t
dispatch_t = Σ dispatch_t
batteryPower_t = Σ batteryPower_t
price_t = 平均值(各数据集有效 imb_eg_t)
```

#### KPI 公式

```text
intervalRevenue_t = dispatch_t × price_t
cumulativeRevenue_t = Σ intervalRevenue_t
deviation_t = |bid_t - dispatch_t|

totalSocCapacity = Σ 每个选中数据集的 max(soc_eg)
socPct_t = soc_t / totalSocCapacity × 100

coveragePct = filledPoints / slots.length × 100
```

#### 页面 KPI 对应关系

| 页面指标 | 模型字段 | 说明 |
| --- | --- | --- |
| 区间总收益 | `totalRevenue` | `Σ intervalRevenue_t` |
| 平均投标偏差 | `avgDeviation` | `平均值(deviation_t)` |
| 最大储能功率 | `maxBatteryPower` | `max(abs(batteryPower_t))` |
| SOC 区间 | `socMinPct`, `socMaxPct` | 归一化后最小/最大值 |

## 模块三：运行视图

### 页签一：投标情况 `bid`

| 图表序列 | 模型字段 |
| --- | --- |
| 电价 | `priceSeries` |
| 发电 | `genSeries` |
| 投标 | `bidSeries` |
| 调度 | `dispatchSeries` |

图例口径：

```text
调度量 = 发电量 + 储能电量变化
电价 = imb_eg
```

### 页签二：储能运行 `storage`

| 图表序列 | 模型字段 |
| --- | --- |
| 放电功率 | `dischargePowerSeries` |
| 充电功率 | `chargePowerSeries` |
| SOC | `socPctSeries` |

公式：

```text
dischargePower = max(batteryPower, 0)
chargePower = min(batteryPower, 0)
socPct = soc / totalSocCapacity × 100
```

### 页签三：收益辅助 `revenue`

| 图表序列 | 模型字段 |
| --- | --- |
| 区间收益 | `intervalRevenueSeries` |
| 累计收益 | `cumulativeRevenueSeries` |
| 电价 | `priceSeries` |

公式：

```text
intervalRevenue_t = dispatch_t × price_t
cumulativeRevenue_t = Σ intervalRevenue_t
```

## 模块四：VPP 类型与取数要点

### 侧边信息字段

| 页面字段 | 来源 |
| --- | --- |
| 当前对象 | `selectedVpp` / `datasets[id].meta.longTitle` |
| 资源构成 | `datasets[id].meta.source` |
| 日期范围 | `rangeDates` |
| 数据粒度 | 固定为 `15 分钟` |
| 覆盖率 | `filledPoints`, `coveragePct` |
| 字段 | `columns` |
| 源文件 | `dataset.sourceFile` |

### 取数说明文本

`buildFetchNotes(model)` 会按当前选择拼接说明，规则包括：

| 条件 | 说明文本 |
| --- | --- |
| 所有情况 | 区间总刻度数、调度计算口径、最大储能功率换算方式、收益口径 |
| 包含 `VPP2` | 额外说明夜间缺失时段保留空值，不做插值 |
| 选择 `ALL` | 额外说明发电/投标/SOC/调度求和、电价取均值 |
| 选择单个 VPP | 追加对应 `datasets[id].meta.note` |

## 模块五：训练曲线分析

训练曲线完全由 `assets/analysis-training-curves.js` 提供，不依赖 `visual-data.js`。

| 图表 | 数据源 |
| --- | --- |
| 奖励训练曲线 | `curveData.reward.series.vpp1/vpp2/vpp3` |
| MAE 训练曲线 | `curveData.mae.series.vpp1/vpp2/vpp3` |
| MBE 训练曲线 | `curveData.mbe.series.vpp1/vpp2/vpp3` |

说明：

| 项 | 口径 |
| --- | --- |
| 横轴 | `epochs = 0, 10, 20, ..., 500` |
| 曲线对象 | 三类 VPP：`VPP1 风储`、`VPP2 光储`、`VPP3 光火储` |
| MAE/MBE 解释文字 | 页面内静态说明文本，不来自外部数据 |
