# 系统总览页面数据说明

## 页面入口与直接依赖

| 项目 | 文件/对象 | 说明 |
| --- | --- | --- |
| 页面入口 | `index.html` | 系统总览页面。 |
| 市场数据 | `assets/data.js` -> `window.VPP_MARKET_DATA` | 年度、月度、日内市场与 VPP 参数。 |
| 市场工具 | `assets/market-ui.js` -> `window.MarketUI` | 年份/日期选择、格式化、VPP 收益拆分、表格行生成。 |

| 训练曲线摘要 | `index.html` 内嵌 `trainingCurveSource` | 数值来源与 `assets/analysis-training-curves.js` 保持一致，用于总览摘要。 |

## 上游原始来源

| 前端数据 | 上游来源 | 说明 |
| --- | --- | --- |
| `assets/data.js` | `scripts/build-data.ps1` 读取 `../数据集` | 由电价 CSV、风电 CSV、光伏 CSV、VPP 参数 Excel、算法配置 Excel 生成。 |

## 模块一：基础数据接入总览

### 模块数据映射

| 页面模块 | 数据对象 | 对应字段 |
| --- | --- | --- |
| 年度平均电价 | `MarketUI.yearData(state.year).summary` | `avgPrice` |
| 电价同比 | 当年/上一年 `summary` | `summary.avgPrice - previous.summary.avgPrice`，格式化由 `MarketUI.trend()` 完成 |
| 新能源占比 | `summary` | `renewableShare` |
| 平均新能源出力说明 | `summary` | `avgRenewable` |
| 年度收益估算 | `summary` | `revenueWan` |
| 收益同比 | 当年/上一年 `summary` | `summary.revenueWan - previous.summary.revenueWan` |
| 日内出力与电价图 | `MarketUI.dailySeries(state.date)` | `time`, `solar`, `wind`, `thermal`, `price` |
| 年度市场结构图 | `yearData.monthly`, `summary` | `month`, `avgSolar`, `avgWind`, `avgPrice`, `summary.avgThermal` |
| VPP 资源接入卡片 | `MarketUI.sourceRows(summary)`, `marketData.vpps` | `id`, `name`, `source`, `avgPower`, `annualEnergy`, `status`, `color` |
| 基础数据快照表 | `MarketUI.sourceRows(summary)` | `id`, `source`, `annualEnergy` |

### 关键公式

年度收益估算 `summary.revenueWan` 来自 `scripts/build-data.ps1`：

```text
revenueWan = Σ((wind + solar + thermal) × price × 0.25) / 10000
```

VPP 收益拆分由 `MarketUI.annualRevenueByVpp(summary)` 计算：

```text
VPP1收益 = totalSolarGwh × 1000 × avgPrice / 10000
VPP2收益 = totalWindGwh × 1000 × avgPrice / 10000
VPP3收益 = (totalSolarGwh + totalThermalGwh) × 1000 × avgPrice / 10000
```

VPP 年度简报由 `MarketUI.sourceRows(summary)` 生成：

```text
VPP1平均出力 = avgSolar
VPP2平均出力 = avgWind
VPP3平均出力 = avgSolar + avgThermal

VPP1年发电量 = totalSolarGwh
VPP2年发电量 = totalWindGwh
VPP3年发电量 = totalSolarGwh + totalThermalGwh
```

## 模块二：策略配置快照

### 模块数据映射

| 页面模块 | 数据对象 | 对应字段 |
| --- | --- | --- |
| 算法名称 | `selectedAlgorithm` | `displayName` |
| 核心功能 | `selectedAlgorithm` | `coreFunction` |
| 投标目标 | `selectedAlgorithm` | `objective` |
| 动作定义 | `selectedAlgorithm` | `actionDefinition` |
| 训练预算 | `selectedAlgorithm` | `trainingBudget` |
| 学习率/折扣因子/GAE/裁剪系数 | `selectedAlgorithm.parameters[]` | 通过 `getAlgorithmParam()` 按 `label` 模糊匹配读取 |
| 网络类型/输入维度/隐藏层/输出维度 | `selectedAlgorithm.parameters[]` 或 `vpps[]` | 优先读算法参数，缺失时回退到 `vpps` 静态字段 |
| 关键参数数量 | `selectedAlgorithm.parameters` | `parameters.length` |
| 策略说明摘要 | `selectedAlgorithm` | `displayName`, `objective`, `actionDefinition`, `trainingBudget` |

### 参数匹配规则

首页通过 `getAlgorithmParam(algorithm, patterns, fallback)` 取值：

```text
1. 在 algorithm.parameters[] 中查找 label 包含指定关键字的第一项
2. 命中后优先返回 value
3. value 为空时返回 description
4. 都没有时返回 fallback
```

### 训练曲线快照

总览页的训练曲线是“摘要曲线”，不是按当前算法切换的真实训练日志。

对应数据：

| 序列 | 来源 |
| --- | --- |
| `Reward` | `trainingCurveSource.reward.vpp1/vpp2/vpp3` |
| `MAE` | `trainingCurveSource.mae.vpp1/vpp2/vpp3` |
| `MBE` | `trainingCurveSource.mbe.vpp1/vpp2/vpp3` |

摘要公式：

```text
summarySeries[epoch] = 平均值(vpp1[epoch], vpp2[epoch], vpp3[epoch])
```

说明：

| 项 | 口径 |
| --- | --- |
| 横轴 | `0, 10, 20, ..., 500` 回合 |
| `Reward` | 三类 VPP 收益曲线的逐回合均值 |
| `MAE` | 三类 VPP MAE 曲线的逐回合均值 |
| `MBE` | 三类 VPP MBE 曲线的逐回合均值 |

### 仿真模型口径

区间起止规则：

```text
sharedDates = 选中数据集 dates 的交集
selectableDates = sharedDates[0 : sharedDates.length - horizon + 1]
rangeDates = 从 analysisDate 开始连续取 horizon 天
slots = rangeDates × 96 个 15 分钟刻度
```

单个数据集单个时刻的派生量：

```text
storageDelta_t = -(soc_eg_t - soc_eg_(t-1))
dispatch_t = gen_eg_t + storageDelta_t
batteryPower_t = storageDelta_t / 0.25
price_t = imb_eg_t
```

聚合规则：

```text
gen_t = Σ gen_eg_t
bid_t = Σ bid_eg_t
soc_t = Σ soc_eg_t
dispatch_t = Σ dispatch_t
batteryPower_t = Σ batteryPower_t
price_t = 平均值(各 VPP 有效 imb_eg_t)
```

KPI 公式：

```text
deviation_t = |bid_t - dispatch_t|
intervalRevenue_t = dispatch_t × price_t
cumulativeRevenue_t = Σ intervalRevenue_t

totalSocCapacity = Σ 每个数据集的 max(soc_eg)
socPct_t = soc_t / totalSocCapacity × 100

coveragePct = filledPoints / slots.length × 100
```

有效刻度判定：

```text
如果 gen / bid / soc / price 任一字段为有效数值，则该刻度计入 filledPoints
```
