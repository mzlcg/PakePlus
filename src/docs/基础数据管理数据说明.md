# 基础数据管理页面数据说明

## 页面入口与直接依赖

| 项目 | 文件/对象 | 说明 |
| --- | --- | --- |
| 页面入口 | `data-management.html` | 基础数据管理页面。 |
| 市场数据 | `assets/data.js` -> `window.VPP_MARKET_DATA` | 年度、月度、日内市场数据和 VPP 参数。 |
| 市场工具 | `assets/market-ui.js` -> `window.MarketUI` | 日期、年份、聚合数据读取。 |
| 图形库 | `Vue`、`Element Plus`、`G6`、`ECharts` | 页面展示依赖，不新增数据源。 |

## 上游原始来源

`assets/data.js` 由 `scripts/build-data.ps1` 从 `../数据集` 构建，主要包括：

| 原始文件 | 主要字段 | 页面用途 |
| --- | --- | --- |
| `16-19年电价数据.csv` | `DateTime`, `Marginal incremental price`, `Negative imbalance price` | 15 分钟电价曲线、月度均价 |
| `16年风电数据.csv` 至 `19年风电数据.csv` | `Time`, `Power(MW)` | 风电出力 |
| `16年光伏数据.csv` 至 `19年光伏数据.csv` | `Time`, `Power(MW)` | 光伏出力 |
| `VPP1_光伏储能_机组参数.xlsx` | 光伏容量、储能参数 | `vpps[0]` |
| `VPP2_风电储能_机组参数.xlsx` | 风电容量、储能参数 | `vpps[1]` |
| `VPP3_光伏火电储能_机组参数.xlsx` | 总发电容量、储能参数 | `vpps[2]` |

## 页面状态与筛选

| 状态 | 对应逻辑 |
| --- | --- |
| `selectedDate` | 默认取 `MarketUI.selectedDate()` |
| 可选日期 | `MarketUI.dates()` |
| 日期禁用 | 若日期不在 `MarketUI.dates()` 中则禁用 |
| 当前年份 | `selectedYear = Number(selectedDate.slice(0, 4))` |
| 当前年度数据 | `current = MarketUI.yearData(selectedYear)` |

说明：

```text
本页以“日期”为主筛选条件，月度图表会自动取该日期所在年份的数据。
```

## 模块一：VPP 机组拓扑与物理参数

### 数据来源

该模块的数据来自两部分：

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| VPP 接入节点、主体、资源组合 | 页面内 `vppDeployments` 常量 | 本地静态配置，不来自 `assets/data.js` |
| 装机容量、储能容量、储能功率 | `MarketUI.data.vpps[]` | 来自 VPP 参数 Excel |

### `vppDeployments` 静态映射

| VPP | 接入节点 | 主体 | 资源组合 |
| --- | --- | --- | --- |
| `VPP1` | `3` | `主体A` | `风电 + 储能` |
| `VPP2` | `12` | `主体B` | `光伏 + 储能` |
| `VPP3` | `25` | `主体C` | `火电 + 光伏 + 储能` |

### `vpps[]` 对应字段

| 表格字段 | `vpps[]` 字段 |
| --- | --- |
| 装机(MW) | `capacityMw` |
| 储能(MWh) | `storageMwh` |
| 功率(MW) | `storageMw` |

`vppPhysicalParams` 的组装规则：

```text
对于每个 deployment:
  params = vpps.find(item => item.id === deployment.id)
  capacity = params.capacityMw
  storageMwh = params.storageMwh
  storageMw = params.storageMw
```

说明：

| 项 | 口径 |
| --- | --- |
| 拓扑节点位置 | 由页面内 `scatterPositions` 和 `vppSlots` 静态布局决定 |
| 资源子节点 | 来自 `vppDeployments[].units`，仅用于展示 |
| 该模块无收益/功率推导公式 | 直接展示接入关系和静态参数 |

## 相关字段来源说明

`vpps[]` 由 `scripts/build-data.ps1` 中的 `Get-VppParams` 生成：

| 字段 | Excel 来源 |
| --- | --- |
| `capacityMw` | 封面工作表的发电容量字段 |
| `ratedCapacityMw` | `额定装机容量` |
| `storageMwh` | `储能实际容量 (E_max)` |
| `storageMw` | `储能最大功率 (P_max)` |
| `algorithm` | `算法` |
| `network` | `网络结构` |
| `inputSize` | `输入维度 (in_size)` |
| `hiddenSize` | `隐藏层维度 (hidden_size)` |
| `outputSize` | `输出维度 (out_size)` |

市场聚合字段由 `assets/data.js` 直接提供：

| 字段 | 公式 |
| --- | --- |
| `avgSolar` | `solarSum / count` |
| `avgWind` | `windSum / count` |
| `avgPrice` | `priceSum / count` |
| `totalSolarGwh` | `solarSum × 0.25 / 1000` |
| `totalWindGwh` | `windSum × 0.25 / 1000` |

说明：

| 项 | 口径 |
| --- | --- |
| 本页不直接使用算法配置数据 | 只展示市场曲线和 VPP 静态参数 |
| 本页不读取仿真 Excel 日切片 | 不依赖 `assets/visual-data.js` |
